# siciju.online

> An interactive void officially confirming the total absence of content.

Live site: [https://siciju.online](https://siciju.online)

## Features

- **Interactive Flashlight**: Sweep the void to reveal hidden whispers.
- **Pull-Cord Lamp**: Switch between Dark Void and Light Art Gallery themes.
- **Sound Effects**: Procedural Web Audio API sound design (no external audio assets).
- **Embedded Terminal**: Press `/` or click `>_` to run `siciju-sh` commands (`help`, `ls`, `cat .breeze`, `lamp`, etc.).
- **5 Secret Discoveries**: Explore the void to unlock all achievements and claim an official certificate of nothingness.
- **Zero Dependencies**: Pure HTML5, CSS3, vanilla JavaScript, and 2D Canvas.
